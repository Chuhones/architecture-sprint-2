# pymongo-api

## Проект с добавлением шардирования и репликации

## Как запустить

Если проект запускается впервые и требуется настройка, а также заполнение данными

```shell
./scripts/start_and_init.sh
```

Если проект уже проинициализирован и требуется только запуск

```shell
./scripts/start_only.sh
```
##
## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

##
### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080
##
### Для проверки распределения записей в репликах

```shell
./scripts/shard_and_replica_test.sh
```
##
## Доступные эндпоинты

Список доступных эндпоинтов, swagger http://<ip виртуальной машины>:8080/docs
